配电柜门禁管理系统的设计与实现
元器件：STM32f103c8t6  oled屏幕  asrpro语音识别模块  JQ8900语音播报模块 舵机  矩阵键盘   rfid   继电器 指纹模块  蜂鸣器 按键 ESP8266 led*2
功能：
1.oled显示门禁状态（门禁：开/关）
2.舵机模拟开关门
3.门禁控制：
①通过asrpro识别语音密码（例：1234）是否正确，密码正确则开门，也可通过矩阵键盘输入密码，正确则开门，门开后，通过按键关门或者指令关门
②继电器开关模拟门禁开关，RFID刷卡开门（继电器关闭），10秒后自动关门（继电器打开）
③矩阵键盘输入密码开锁，初始密码为0000，开锁后可修改密码，开锁时密码错误超过三次，蜂鸣器+led声光报警，密码错误时jq8900语音播报“密码错误”
④配备矩阵键盘，支持密码输入解锁，并可通过动态密码（app下发）实现临时开锁。管理员可通过键盘密码进入管理界面，管理用户信息。
⑤配备指纹识别模块，支持用户指纹录入与识别，验证成功后开锁。管理员模式需通过管理员指纹验证进入后台界面。
4.门禁为关时，红色led亮起。门禁为开时，绿色led亮起
5.蜂鸣器报警：按键控制报警功能的开关，开门超过10秒没有关闭，蜂鸣器报警
6.app：显示门禁状态，控制开门关门，控制蜂鸣器报警功能的开关

开/关门：语音识别/矩阵键盘（初始状态）/RFID/指纹/APP直接控制/APP下发动态密码
管理员密码/管理员指纹进入后台界面
密码错误三次报警

页面1——锁定页面&选择开锁方式&APP直接开锁（失败三次蜂鸣器报警）&按键控制报警功能的开关
页面2——按键开锁（矩阵键盘|语音开锁）
页面3——RFID刷卡开锁
页面4——指纹开锁
页面5——开锁成功&按键上锁&语音上锁&自动上锁
页面6——管理密码
页面7——管理门禁卡
页面8——管理用户指纹
页面9——上锁
页面10——修改用户密码
页面11——修改管理员密码
页面12——添加卡
页面13——删除卡
页面14——添加指纹（管理员/用户）
页面15——删除指纹
页面16——添加用户指纹
页面17——添加管理员指纹
