便携式心率检测仪（6cm*5cm）
元器件：STM32f103c8t6  0LED  MAX30102  W25Q64  锂电池  esp8266  led*2 按键
功能：
1.MAX30102检测心率血氧，测量范围50-180次/分钟，误差≤5次/分钟；
2.OLED显示参数和实时时间，心率＞100次/分钟时红色LED闪烁提醒，＜60次/分钟时蓝色LED闪烁
3.支持按键存储心率血氧数据，按下保存按键，保存此时的心率血氧和实时时间，可通过串口将保存的数据发送到串口助手查看，可按键清除储存数据

LED1——红灯
LED2——蓝灯

按键1——页面切换
按键2——光标移动
按键3——光标处确认

页面1——显示当前心率血氧（1行）、实时时间（2行）、存储/清除数据（1行）（1——_2）
页面2——存储数据查看（2——7/_1）
页面3——存储中（3——5）
页面4——清除中（4——6）
页面5——存储成功/存储失败（5——_1）
页面6——清除成功/清除失败（6——_1）
页面7——查看存储数据1（7——_8）
页面8——查看存储数据2（8——_9）
页面9——查看存储数据3（9——_2）
