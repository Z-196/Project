基于物联网的卧室智能置物柜控制系统设计
元器件：STM32f103c8t6  0LED  按键 LED(PWM)  ESP8266 舵机 ASRPRO  外部RTC时钟模块 指纹识别模块

WiFi模块:与手机APP建立连接，传输系统各模块的状态数据;接收APP指令，调整系统的部分参数
APP:显示系统各模块的实时状态;远程调整系统的部分参数。
灯光模块:支持多档位调节，可通过按键、语音指令控制;
OLED显示屏:显示时钟模块的时间、显示灯光当前的档位状态
按键模块:控制灯光的档位切换、设置时钟模块的时间:
舵机模块:接收指纹识别模块的触发信号，通过转向控制置物柜的开合(实现上锁、开锁，保护隐私):
时钟模块:内置电池，断电后时间无需重新校准:提供时间数据，用于OLED显示屏的时间显示:
指纹识别模块:识别指纹，触发舵机动作，控制置物柜抽屉开合(实现上锁、开锁)
语音识别模块:识别语音指令，控制灯光的档位切换开关灯;与扬声器联动，触发报时、操作反馈等语音输出。
扬声器模块:与语音识别模块联动，实现报时功能;对操作(如灯光开关)进行语音反馈(例:“灯光已打开”)
充电模块:TYPE-C充电模块;
睡眠模式联动：APP或者语音触发“睡眠模式”，自动关闭灯光，锁定置物柜，同时降低扬声器音量。
